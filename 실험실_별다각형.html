별 다각형 실험실

슬라이더로 별을 바꿔 규칙을 찾고, 증명을 블록으로 쌓고, 반례를 사냥한다.

문제

원 위에 n 개의 점이 같은 간격으로 찍혀 있다. 한 점에서 출발해 k 칸씩 건너뛰며 선분으로 이어 나가면 언젠가 출발점으로 돌아온다. 이렇게 그린 도형을 {n/k} 라 쓴다.

  • n 과 k 의 최대공약수가 1 이면 n 개의 점을 하나도 빠짐없이 지나 한 붓으로 그려진다.
  • k 와 n − k 는 도는 방향만 반대인 같은 그림이므로 1 ≤ k < n/2 만 본다.
  • k = 1 이면 볼록한 n 각형이다.

{n/k} 의 꼭짓점 n 개에서 뾰족한 각을 모두 더하면 얼마인가.

1·4주차에서 각을 잰 오각별 {5/2} — 각의 합이 180° 였다 — 를 모든 {n/k} 로 넓힌 것이다.

주장

{n/k} — 원 위에 같은 간격으로 찍은 n개 점을 k칸씩 건너뛰며 한 붓으로 잇는다.

튼 각 — 그 붓이 꼭짓점에서 진행 방향이 꺾인 각(외각).

각의 합 = 180(n − 2k)

한 각 = 180(n − 2k)/n

조건은 gcd(n, k) = 1(둘의 최대공약수가 1)과 1 ≤ k < n/2. k = 1이면 볼록 n각형이다.

슬라이더로 n과 k를 바꾼다. 캔버스의 꼭짓점을 누르면 그 각을 잰 값이 뜬다. 캔버스에 포커스를 두면 ← →가 k를, ↑ ↓가 n을 바꾼다.

몇 바퀴 도는가로 세는 논법

    
별을 한 붓으로 그릴 때 손은 직선으로 나아가다 꼭짓점에서만 방향을 튼다. 튼 각이 외각이고, 꼭짓점의 각은 180° − 외각이다.

    
출발점으로 돌아오면 손이 향한 방향도 출발할 때와 같다. 따라서 튼 각을 전부 더하면 360°의 배수가 되고, 몇 배인지가 곧 몇 바퀴 돌았는가다. k칸씩 건너뛰면 한 바퀴 도는 동안 원을 k번 감으므로 그 배수는 k다.

    
그러면 n × 외각 = 360k, 즉 외각은 360k/n이고 한 각은 180 − 360k/n = 180(n − 2k)/n이다. n배 하면 180(n − 2k). k = 1을 넣으면 180(n − 2) — 볼록 다각형 공식이 이 식의 한 경우다.

  


  

    
아직 안 닫힌 곳

    
여기부터는 우리가 증명하지 못한 것이다. 잰 수치는 있고 이유가 없다.


    

      
01 조각으로 갈라져도 합이 그대로인 이유 안 닫힘

      
확인함gcd(n, k)가 1이 아니면 한 붓으로 안 그려지고 별이 조각으로 갈라진다. 아래는 그런 별을 이 쪽에서 직접 잰 표다.

      

      
확인함조각이 몇 개인지는 나머지로 나온다. 꼭짓점 번호는
      0, k, 2k, 3k, … 로 가며 n 으로 나눈 나머지를 도는데,
      처음 0 으로 돌아오는 때가 k 를
      n / gcd(n, k) 번 더했을 때다. 그래서 한 조각에 든 꼭짓점이
      n / gcd(n, k) 개, 조각이 gcd(n, k) 개다.

      
안 닫힘안 닫힌 것은 그다음이다 — 조각으로 갈라져도 각의 합이
      180(n − 2k) 그대로인 이유. 표에서 재 보기만 했다.
      우리 증명은 한 붓으로 이어질 때만 다뤘다.

    


    

      
02 방향이 왜 처음으로 돌아오는가 안 닫힘

      
안 닫힘증명에서 「출발점으로 돌아오면 붓이 향한 방향도 처음과 같다」를 그냥 썼다. 왜 반드시 그런지는 증명하지 않았다. 이것이 무너지면 360k도 같이 무너진다.

    


    

      
03 원 위가 아니어도 되는가 안 닫힘

      
안 닫힘우리 증명은 같은 간격으로 찍은 점만 다뤘다. 점을 원에서 떼어 흔들면 각의 합이 어떻게 되는지 눌러서 잰다. 차례는 그대로 두고 반지름과 각도만 흔든다.

      

        
        
      

      
눌러서 재 본다. 흔든 별마다 잰 합을 180(n − 2k)와 견준다.

      올리고 돌린다. 별 13,696개, 꼭짓점 2,741,751개를 좌표에서 잰다.
      각의 합 = 180(n − 2k)는 반례 0, 최대 어긋남
      4.5 × 10⁻¹³도 — 소수점 아래 열두 자리까지 같다는 뜻이다.

      
아직 안 닫힌 곳의 03에서 점을 흔들어 400번 재기를 눌러도
      같은 값이 나온다. 원 위가 아니어도 합이 버티는지를 그 자리에서 잰다.

    


    

      
밖에서 아홉 줄이면 된다

      
n과 k를 바꿔 가며 두 줄이 같은 수를 찍는지 본다.

      
from math import cos, sin, pi, atan2, degrees
n, k = 9, 4                                    # 별 {9/4}
P = [(cos(2*pi*j/n), sin(2*pi*j/n)) for j in range(n)]
def ang(j):                                    # 꼭짓점 j 의 각
    x, y = P[j]; ax, ay = P[(j-k) % n]; bx, by = P[(j+k) % n]
    ux, uy, vx, vy = ax-x, ay-y, bx-x, by-y
    return degrees(atan2(abs(ux*vy - uy*vx), ux*vx + uy*vy))
print(sum(ang(j) for j in range(n)))           # 점을 찍어 잰 합
print(180*(n - 2*k))                           # 공식이 말하는 값

      
이 쪽이 쓰는 방법과 같다 — 공식끼리 견주지 않고 점을 찍어 각을 잰다.
