# 증명의 집

주소: https://iseungsang01.github.io/2026-lab/

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 증명의 집 (첫 화면, 지도와 방) |
| `견본_거리의합과중앙값.html` | 로비 실험실 |
| `실험실_원위의말.html` | 대수의 방 |
| `실험실_별다각형.html` | 기하의 방 |
| `실험실_파스칼mod2.html` | 조합의 방 |
| `실험실_카드3연속.html` | 정보의 방 |
| `문항/*.svg` | 방마다 붙는 원본 문제 그림 |

## 고치는 법

**한 파일만 조금 고칠 때**
1. 위 목록에서 파일을 누른다.
2. 오른쪽 위 연필 아이콘을 누르고 코드를 고친다.
3. **Commit changes** 를 누른다.

**여러 파일을 한꺼번에 고칠 때**
저장소 화면에서 키보드 `.` 을 누르면 브라우저 안에 편집기가 열린다. 고친 뒤 왼쪽 소스 제어 칸에서 커밋한다.

**내 컴퓨터에서 고친 파일을 올릴 때**
**Add file → Upload files** 로 같은 이름의 파일을 끌어다 놓고 **Commit changes** 를 누른다. 같은 이름이면 덮어쓴다.

커밋하고 1분쯤 지나면 주소의 페이지가 바뀐다. 안 바뀌면 새로고침(Ctrl+Shift+R)한다.

## 망가뜨렸을 때

**History** 에서 이전 커밋을 열어 그 때의 파일 내용을 그대로 다시 붙여 넣으면 된다. 지난 모든 버전이 남아 있다.
