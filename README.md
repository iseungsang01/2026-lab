# 증명의 집

주소: https://iseungsang01.github.io/2026-lab/

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 증명의 집 (첫 화면, 지도와 방) |
| `견본_거리의합과중앙값.html` | 로비 실험실 |
| `실험실_원위의말.html` | 대수의 방 |
| `실험실_별다각형.html` | 기하의 방 |
| `실험실_파스칼mod2.html` | 조합의 방 |
| `실험실_카드3연속.html` | 정보의 방 |
| `문항/*.svg` | 방마다 붙는 원본 문제 그림 |

## 고치는 법

1. 초록색 **Code** 단추에서 **Download ZIP** 을 눌러 받고 압축을 푼다. 계정이 없어도 된다.
2. 고칠 파일을 메모장이나 VS Code 로 열어 고친다.
3. 저장하고 그 파일을 더블클릭하면 브라우저에서 바로 결과가 보인다. 증명의 집 안에서 보려면 `index.html` 을 연다.
4. 다 고친 파일을 멘토에게 보낸다. 멘토가 올리면 1분쯤 뒤 주소의 페이지가 바뀐다.

파일 이름은 바꾸지 않는다. 증명의 집이 이름으로 실험실을 찾는다.
