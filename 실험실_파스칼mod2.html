파스칼 mod 2 실험실

삼각형을 칠해 무늬를 찾고, 더 작은 경우로 되돌리는 증명을 블록으로 조립하고, 반례를 사냥한다.

문제

파스칼 삼각형의 n 행은 C(n,0), C(n,1), …, C(n,n) 으로 모두 n+1 개다. 그중 홀수인 것의 개수를 f(n) 이라 하자.

  • 0 행은 1 하나뿐이므로 f(0) = 1.
  • 4 행은 1 4 6 4 1 이라 홀수는 양 끝의 1 둘, f(4) = 2.
  • 7 행은 1 7 21 35 35 21 7 1 이라 여덟 개가 모두 홀수, f(7) = 8.

n 행을 실제로 세어 보지 않고, n 만 보고 f(n) 을 구할 수 있는가.

6주차 충북과학고 2023 문항 6 — 관람석을 「앞 사람과 앞왼쪽 사람의 색이 다르면 파랑」으로 칠했을 때 파랑이 앉는 자리가 곧 파스칼 삼각형의 홀수 자리다.

주장

f(n) = 2^(n의 2진법 1의 개수)

f(n)은 파스칼 삼각형 n행의 홀수 개수. n행은 C(n,0) … C(n,n)으로 n+1개다.

삼각형의 행을 누르면 그 행이 잡힌다. 오른쪽 표의 줄을 눌러도 같다. 잡은 행과 함께 2n·2n+1 행도 표시된다.

더 작은 경우로 되돌리는 논법

    
0행부터 2ᵏ−1행까지를 블록 T라 한다. 그 아래 2ᵏ행부터 2ᵏ⁺¹−1행까지에는 T와 똑같은 무늬가 왼쪽과 오른쪽에 하나씩 놓이고, 그 사이는 전부 0이다. 홀짝만 보면 C(n,k) ≡ C(n−2ᵏ, k) + C(n−2ᵏ, k−2ᵏ)이고, 두 항은 k의 범위가 겹치지 않아 서로 더해지지 않기 때문이다.

    
그래서 2n행은 n행과 홀수 개수가 같고, 2n+1행은 왼쪽·오른쪽 두 복제가 동시에 살아 있어 두 배가 된다. 두 줄이 f(2n) = f(n), f(2n+1) = 2f(n)이다.

    
2진법으로 n을 쓰면 n → 2n은 뒤에 0을 붙이는 것, n → 2n+1은 1을 붙이는 것이다. 0은 f를 그대로 두고 1은 두 배로 만들므로, f(0) = 1에서 시작해 1의 개수만큼 두 배가 된다.

    
두 줄짜리 점화식 f(2n) = f(n), f(2n+1) = 2f(n)이 증명의 전부다. 더 작은 경우로 되돌린다는 것은 n을 반으로 줄여 가며 0까지 내려간 뒤, 올라오면서 값을 되받는다는 뜻이다. 내려갈 때 나온 나머지를 거꾸로 읽으면 n의 2진법 표기가 된다.

  


  

    
아직 안 닫힌 곳

    
여기부터는 우리가 증명하지 못한 것이다. 잰 수치는 있고 이유가 없다.


    

      
01 mod 3 에서도 같은 꼴의 식이 있는가 안 닫힘

      
확인함mod 3으로 칠해도 확대해서 같은 무늬가 나온다. 3으로 나눠떨어지지 않는 수의 개수를 g(n)이라 한다. n을 3진법으로 쓴 각 자리에 1을 더해 전부 곱하면, n = 0…2048에서 g(n)과 한 번도 어긋나지 않았다.

      

        
n3진법자리별 (자릿수+1)의 곱g(n) 실측

        
          
4112 × 2 = 44

          
5122 × 3 = 66

          
6203 × 1 = 33

          
8223 × 3 = 99

        
      

      
안 닫힘왜 그런지는 증명하지 못했다. 밀어 볼 방향 — mod 2에서 두 갈래로 되돌린 것을 mod 3에서는 세 갈래로 해 본다. g(3n)·g(3n+1)·g(3n+2)가 각각 g(n)의 몇 배인지 표로 재 보면 답이 보인다.

    


    

      
02 mod 4 는 왜 무늬가 다른가 안 닫힘

      
확인함실험대의 자리별 곱과 어긋난 칸이 mod 2·3·5·7에서는 0이고, 4·6·8·9에서는 0이 아니다(행 0~255에서 4,905 · 14,188 · 10,743 · 7,608칸). 소수일 때만 맞는다.

      
안 닫힘왜 소수여야 하는지는 수치로만 봤다. 실마리 — mod 4에서 가장 먼저 어긋나는 칸은 C(4,2) = 6이다. 4로 나눈 나머지는 2다. 그런데 자리를 맞춰 쪼개면 4 = 10₄, 2 = 02₄라 자리별 곱은 C(1,0) × C(0,2) = 0이 된다. 이 한 칸부터 따라가 본다.

    


    

      
03 홀수를 0행부터 다 더하면 안 닫힘

      
확인함실험대의 0 아닌 칸이 곧 f(0) + f(1) + … + f(행수−1)이다. 행 수를 2의 거듭제곱으로 놓으면 값이 전부 3의 거듭제곱이 된다.

직접 확인해 보시오


    

      
화면 안 범위를 끝까지 밀어 전수로 센다

      
반례 사냥 탭에서 n의 범위를 8192까지 늘려
      돌린다. f(n) = 2^(1의 개수)는 반례 0이다. 같은 자리에서
      f(n) = 2^(2진법 자릿수)로 바꾸면 거의 전부가 반례로 뜬다 —
      1의 개수와 자릿수 한 낱말 차이다.

      
실험대의 행별 세기 표에서는 행마다 f(n) 실측과
      2^(1의 개수)가 한 줄에 나란히 뜬다. 행 수를 256까지
      올려도 두 칸이 갈라지는 줄이 없다.

    


    

      
밖에서 일곱 줄이면 된다

      
이 쪽이 적은 수는 전부 파스칼 행을 실제로 만들어 센 값이다. 같은 것을 직접 만든다.

      
row = [1]                          # 0 행
for n in range(33):
    print(n, bin(n)[2:], sum(row)) # n · 2진법 · 홀수 개수
    nxt = [1] * (len(row) + 1)     # 양 끝은 늘 1
    for k in range(1, len(row)):
        nxt[k] = (row[k-1] + row[k]) % 2
    row = nxt

      
row에는 0과 1만 들어 있으므로 sum(row)가 곧
      홀수의 개수다. % 2를 % 3으로 바꾸고
      sum(row)를 sum(v != 0 for v in row)로 바꾸면
      아직 안 닫힌 곳 01의 g(n)을 잰다.
