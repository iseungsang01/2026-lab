연속해서 가져갈 수 없는 카드

카드 수 n 과 금지하는 연속 장수 k 를 바꿔 가며, 가능한 경우를 파이썬이 하나씩 만들어 세는 것을 본다.

문제

카드 n 장이 한 줄로 놓여 있다. 영희는 왼쪽 끝부터 한 장씩 가져갈지 말지 정하는데, 세 장을 연속해서 가져갈 수는 없다. n = 5, n = 8 일 때 가능한 경우의 수와, k 장 연속 금지로 바꿨을 때 경우의 수를 구하는 방법을 묻는다.
