카드 3연속 실험실

카드를 눌러 가며 가능한 배치를 전부 세어 규칙을 찾고, 끝 세 갈래로 나누는 증명을 블록으로 조립하고, 반례를 사냥한다.

문제

철수가 영희에게 카드 n 장 중 몇 장을 주려 한다. 영희는 왼쪽 끝 카드부터 오른쪽 끝 카드까지 가면서 한 장씩 가져갈지 안 가져갈지를 고른다. 한 장도 안 가져가도 된다.

  • 단, 세 번 연속해서 가져갈 수는 없다.
  • 가져간 카드가 무엇인지는 따지지 않는다. 어느 자리를 골랐는가만 센다.
  • 예 — □■■□■□ 는 되고, □□□■■■ 는 안 된다.

가능한 경우의 수는 몇 가지인가. n = 5 일 때와 n = 8 일 때를 구하고, 「세 번」을 「k 번」으로 바꾸면 어떻게 되는지도 말하시오.

7주차 충북과학고 2026 문항 5. 원문의 질문 1·2·3 을 그대로 쓴다.

주장

a(n) = a(n−1) + a(n−2) + a(n−3)

a(n) 은 카드 n 장짜리 가능한 배치의 수. a(0) = 1(아무것도 안 가져감), a(1) = 2, a(2) = 4 에서 시작한다. k 번 연속 금지면 갈래가 k 개다.

카드를 누르면 가져감과 안 가져감이 바뀐다. 화살표 키로 옮기고 Enter 로 눌러도 된다.

끝을 보고 나누는 논법

    
세는 문제에서 가장 먼저 물을 것은 어디를 보면 문제가 작아지는가이다. 여기서는
    맨 오른쪽 끝이다. 끝에서 가져간 카드가 몇 장 연속인지는 0·1·2
    셋뿐이다 — 3 은 금지라 없다.

    
끝이 □(안 가져감)이면 그 앞 n−1 장은 조건만 지키면
    아무렇게나 놓아도 된다. 끝이 □■이면 가져간 앞 자리는 반드시 안 가져감이어야
    하므로 그 앞 n−2 장이 자유롭고, □■■이면 n−3 장이 자유롭다.
    자유로운 부분은 다시 같은 문제다.

    
a(n) = a(n−1) + a(n−2) + a(n−3)

    
세 갈래는 겹치지 않는다 — 끝 모양이 서로 다르기 때문이다. 빠지는 것도 없다 —
    끝의 연속이 0·1·2 말고는 있을 수 없기 때문이다.
    세는 문제에서 겹침 없음과 빠짐 없음 둘을 다 말해야 「더하면 된다」가 성립한다.

    
k 번 연속 금지로 바꾸면 끝의 연속이 0 … k−1 이라
    갈래가 k 개가 되고, 같은 논법이 a(n) = a(n−1) + … + a(n−k) 를 준다.
    k = 2 면 피보나치다.

화면 안 범위를 끝까지 밀어 전수로 센다

      
반례 사냥 탭에서 n 을 22 까지 밀고
      a(n) = a(n−1) + a(n−2) + a(n−3) 을 돌린다. 반례 0.
      같은 자리에서 a(n) = 2·a(n−1) − 1 로 바꾸면
      n = 3·n = 4 는 맞다가 n = 5 부터 어긋난다.

      
실험대에서는 이 n 의 배치를 전부 세기를 누르면 가능한 배치를 하나씩 다 만들어 센다.
      n = 5 면 24, n = 8 이면 149 다 —
      원문의 질문 1·2 의 답이 그 자리에서 나온다.

    


    

      
밖에서 열 줄이면 된다

      
점화식을 믿지 않고, 가능한 배치를 하나도 빠짐없이 만들어 센 값과 견준다.

      
from itertools import product
def count(n, k):                       # 전부 만들어 세기
    t = 0
    for s in product([0, 1], repeat=n):
        run = best = 0
        for v in s:
            run = run + 1 if v else 0
            best = max(best, run)
        if best < k: t += 1
    return t
print([count(n, 3) for n in range(9)])  # [1, 2, 4, 7, 13, 24, 44, 81, 149]
